# Airport Management System

A Win32 graphical interface application built in C++ that simulates an airport runway takeoff queue. It uses a First-In-First-Out (FIFO) queue data structure to manage airplanes waiting for takeoff.

## Features

- **Add Plane**: Add a new flight to the runway queue by specifying its Flight Number and Airline.
- **Allow Takeoff**: Process the takeoff of the plane at the front of the queue, removing it from the runway.
- **Queue Status Checks**: Easily check if the queue is empty, full, or view its current capacity (maximum capacity is set to 5 planes).
- **Front Plane Info**: View the details of the next plane scheduled for takeoff without removing it from the queue.
- **Data Persistence**: 
  - The current state of the queue is automatically saved to `runway.txt` and loaded when the application starts. So if you close the app, your queue will remain intact upon reopening!
  - A log of all completed takeoffs is continuously appended to `takeoff_log.txt`.
- **Graphical Interface**: A native Windows GUI displaying a scrollable list box of queued planes with interactive buttons for all queue operations.

## Technical Details

- **Language**: C++
- **API**: Native Win32 API (`<windows.h>`)
- **Data Structures**: Standard Template Library (STL) `<queue>` and `<vector>`.
- **File I/O**: `<fstream>` for reading and writing states to `.txt` files.
- **OS**: Microsoft Windows

## How to Compile and Run

To compile and run this project, you will need a C++ compiler that targets Windows and supports the Win32 API (such as MinGW `g++` or Microsoft Visual C++).

### Using MinGW (g++)
Open your terminal or command prompt in the project directory and compile using:

```bash
g++ airport.cpp -o airport.exe -mwindows
```
*(The `-mwindows` flag links the executable as a GUI subsystem program, preventing a blank command prompt window from appearing in the background.)*

After compiling, simply run the generated executable:
```bash
./airport.exe
```

### Using Microsoft Visual Studio
1. Open Visual Studio and create a new **Windows Desktop Application** (C++) project.
2. Replace the autogenerated code in the main source file with the contents of `airport.cpp`.
3. Build and run the project (F5).

## Project Structure

- `airport.cpp`: The core C++ source code containing the queue logic and the UI application window procedure.
- `runway.txt`: Automatically generated text file used to persist planes currently waiting in the queue.
- `takeoff_log.txt`: Automatically generated append-only text file logging the planes that have already taken off.
- `README.md`: This project documentation file.
